# Homebrew Tap for oobo

[oobo](https://oobo.ai) is an AI coding analytics tool — track sessions, tokens, and code attribution across all your AI tools.

## Install

```sh
brew install ooboai/tap/oobo
```

## Update

```sh
brew upgrade oobo
```

## What is oobo?

oobo sits alongside your AI coding tools (Cursor, Claude Code, Gemini CLI, Windsurf, Aider, and more) and automatically tracks:

- **Sessions** — every conversation with every AI tool
- **Tokens** — real input/output/cache token counts
- **Attribution** — which lines of code were written by AI vs. human
- **Stats** — streaks, heatmaps, model usage breakdowns
- **Card** — shareable developer card with your AI coding stats

## Manual

```
oobo --help
```
